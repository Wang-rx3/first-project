# 相对测距协方差保护核查（2026-10-12）

本笔记用于审查当前代码的数学表述，不提出替换滤波算法，也不修改传感器参数。

原始论文 [A Method for Dealing with Assignment Ambiguity](https://skoge.folk.ntnu.no/prost/proceedings/acc04/Papers/0735_FrA06.5.pdf)（Simon J. Julier、Jeffrey K. Uhlmann、David Nicholson）说明，Covariance Union 的一致性约束需要覆盖输入估计及均值平移带来的不确定性。仅在改变均值后恢复原协方差，不能直接视为该算法的实现或引用其保证。

当前 `LocalEKF.update_relative_range` 对方向上的未知相关性加入 Cauchy–Schwarz 方差上界。对**差分创新方差**取上界有数学依据；但它未维护本机误差与创新的实际互协方差。创新方差上界、均值增益和最终误差协方差的一致性是不同问题。

独立的标量线性反例：本机误差方差 1、邻居误差方差 4、交叉协方差 2；联合矩阵 `[[1,2],[2,4]]` 的特征值为 0 和 5，因此合法。测距独立噪声方差取 0.0064，代码形式给出增益 `1/9.0064 = 0.111032154912`。完全正相关情况下，更新后的本机误差为原本机误差的 `1 + gain` 倍，加上测距噪声的增益倍；方差为 **1.234471349341**，大于恢复的 1。

这是假设范围内的代数反例，不是对实际校准误差方差的测量，也不否定全部 EKF、CI 或 CU 方法。实际校准使用真实初态初始化，报告协方差本身比实测即时误差大；不能把上述反例写成当前轨迹已经发散。

本轮保持融合运行逻辑不变，保留其防止重复收缩的工程作用；停止宣称它提供普遍保守保证。下一步需要独立核查未知相关性的均值与协方差一致性，再决定是否修复融合。不能删除保护、把线性更新中间协方差下降当作最终定位精度提升，或用真实误差作执行期 Actor 输入。
