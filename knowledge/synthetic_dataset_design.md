# 纯 Python 多无人机联合优化数据集设计

## 研究定位

本项目的数据集是由纯 Python 环境按 episode 生成的、可重复的交互式数据集，不拼接公开数据，也不依赖外部仿真器。环境使用 NumPy 实现三维运动、障碍物、传感器、信道、拓扑和 EKF，并通过 PyTorch 提供 GAT/MAPPO 所需的张量接口。

## 固定采样率

| 数据流 | 采样率 |
| --- | ---: |
| 物理状态、ground truth、IMU | 100 Hz |
| UWB、视觉里程计、通信链路 | 10 Hz |
| GNSS | 5 Hz |
| MAPPO 动作和奖励 | 5 Hz |

所有表使用 ENU 坐标、米、秒和弧度，并通过 `episode_id`、`scenario_id`、`seed`、`timestamp`、`split` 关联。若实验配置改变采样率，必须在 `scenario.json` 和 `manifest.json` 中记录。

## Episode 文件

每个 episode 必须包含场景配置、ground truth、IMU、UWB、视觉里程计、GNSS、通信链路、逐包事件、动作、奖励、障碍物和汇总轨迹。`packet_events.csv` 是重新计算丢包、时延和 AoI 的依据，不能只保留聚合后的链路指标。`episode-v1.2` 还应包含估计状态、协方差、图特征和动作掩码。

## 场景划分

- 训练集使用配置指定的无人机规模（通常包含 3、5 架）；
- 验证集使用未用于训练的随机种子和场景布局；
- 测试集使用未见布局、障碍物组合、通信条件和无人机规模（可包含 7 架）；
- 不按同一条轨迹的相邻时间片切分训练集和测试集；
- 每个 split 只使用自身生成的 episode，验证/测试不得反向拟合归一化统计量。

## 参数来源与可重复性

传感器噪声、信道参数、障碍物运动参数、队列参数和奖励尺度均来自版本化的 Python 配置。正式实验前通过控制变量实验、重复随机种子、敏感性分析和消融实验确认参数合理性；不使用公开数据集进行校准。

每个输出目录至少保存：

- `manifest.json`：环境版本、配置、随机种子和 schema；
- `scenario.json`：单回合场景参数；
- `normalization_stats.json`：只由训练回合拟合的归一化统计量；
- `calibration/`：当前 Python 配置及其状态，明确 `external_dataset_required: false`；
- episode CSV、训练指标、注意力诊断和模型检查点。

## 研究解释边界

该数据集可以支持环境—EKF—GAT—MAPPO 的闭环实施性、消融实验、参数敏感性和场景泛化研究；它不能单独证明对真实飞行环境的外部有效性。论文中应把结论表述为“在所定义的纯 Python 统计仿真环境中验证”，不要声称完成真实飞行或公开数据集验证。
