# 课题数据源最终决策

> 状态：当前研究规范（2026-08-09 更新）。
>
> 本文件已经覆盖此前“公开数据集分模块验证、公开数据校准通信参数”的旧方案。后续研究、训练、验证、测试和参数敏感性分析均不使用公开数据集；所有实验数据由项目自己的纯 Python 仿真环境生成。

## 当前数据路线

| 研究环节 | 当前数据来源 | 作用 |
| --- | --- | --- |
| 环境与场景 | `src/simulation/` 的纯 Python 环境 | 生成三维运动、障碍物、LOS/NLOS、传感器和信道状态 |
| 定位观测 | `src/simulation/sensor_model.py` | 生成 IMU、UWB、视觉里程计和 GNSS 观测及其失效模式 |
| 信道观测 | `src/simulation/channel_model.py` | 根据位置、遮挡、带宽、队列和随机种子生成链路质量、丢包、时延和 AoI |
| 协同定位与图状态 | `src/simulation/ekf.py`、`topology.py`、`graph_interface.py` | 生成 EKF 估计、协方差、有效图、GAT 节点/边特征 |
| 强化学习数据 | `src/experiments/pilot.py`、`formal.py` | 生成训练、验证、测试 episode、动作、奖励和 MAPPO 日志 |
| 工程接口 | 当前不作为数据源 | PX4/Gazebo 或 Flightmare 只保留为未来兼容/迁移选项，不进入当前主实验依赖 |

## 统一数据边界

```text
Python 场景配置与随机种子
    → 运动、障碍物、传感器与统计信道
    → Distributed EKF 状态与协方差
    → 有效通信图、GAT 特征与局部观测
    → MAPPO 动作、奖励和下一状态
    → episode、指标、图和训练日志
```

所有实验必须保存：场景配置、代码/模型版本、随机种子、schema 版本、归一化统计量和参数来源。参数合理性通过以下方式检查，而不是通过公开数据集校准：

- 控制变量扫描（距离、遮挡、带宽、队列、噪声和失效模式）；
- 多随机种子重复实验；
- 参数敏感性分析；
- 消融实验和未见场景泛化测试。

## 历史调研资料的边界

此前深度调研中记录的公开无人机、UWB 和无线通信数据集只用于理解已有研究的系统模型、指标和参数量级，不作为本项目的训练集、验证集、测试集或校准输入。相关原始论文和报告继续保存在 `knowledge/`，但不得被代码或正式实验流程自动读取。

## 当前禁止事项

- 不拼接或转换公开数据集作为本课题实验输入；
- 不把公开数据集的统计量写入默认通信/传感器参数；
- 不把 Flightmare、PX4/Gazebo 或其他外部仿真器标记为当前主数据源；
- 不使用未经记录的手工参数覆盖版本化 Python 配置。
