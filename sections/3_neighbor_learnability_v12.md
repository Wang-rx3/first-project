# V12 协同定位邻居选择可学习性诊断与最小代理验证

日期：2026-10-13。结论：**本轮 MAPPO 科学准入未通过，training_ready=false。** 未训练、未部署、未提交或推送。

## 1. 结论与原因分层

1. **已证实的评分问题（B）**：v11 原评分的独立几何、可靠性正加分会在原 CI 预测不更新时继续鼓励测量。464 个 Greedy 请求中，397 个窗口的两个候选都预测不更新：开发 203/232，原确认 194/232。评分不是经过验证的真实定位收益或通信效用。
2. **有限支持的状态限制（A）**：迹不能表达本机误差椭球的方向。新增沿每个邻居方向的本机/邻居位置投影方差，是四个标量的最小编码诊断，方向向量另作审计。它未形成可靠跨种子的邻居价值映射。原 Greedy 的 CI 克隆已经使用完整协方差和方向，不能把这项编码称为向原规则提供了新信息，也不能仅凭弱单变量相关证明完整观测没有信息。
3. **尚不能确定的任务限制（C）**：有真实收益差异，但大量窗口两种动作无实际区别；不同参考的定位协方差各向同性、消息 AoI 相同，使若干候选状态缺少竞争信号。当前证据不足以证明不存在可学习的条件期望收益规律，也不足以支持直接训练 GAT+MAPPO。
4. **独立确认暴露的执行层问题**：新种子 2026101324 在两种几何、四种策略均于第 3 步触发 `stationary_start_unsupported: relative VO motion exceeds startup limit`。发生在第一次协同窗口前，不能归因于邻居规则。未排除该种子、改变初始化或放宽门限。异常步传感器/滤波上下文未在原停止记录中完整保存；目前不能确认具体 UAV、创新值或底层失效原因。

## 4. 最小状态与代理检验

在线最小规则在动作前 `(step−1)×0.2 s` 使用本机估计和已到达邻居消息，调用与 v11 相同的原 CI 零创新克隆：

```text
候选分数 = 克隆前后 3×3 位置协方差迹下降(m²) − 0.01(m²/请求单位)
none 分数 = 0
只请求严格正分的合法候选；并列使用冻结 v12_minimal_tie 随机流。
```

0.01 是固定的诊断取舍，不是平方米与字节的物理换算；未调参、未拟合。每次请求使用原 512-byte-equivalent 会计单位，未宣称完整报文或实际链路字节。RSSI/AoI/Delay 可作为观测及审计元数据，但未作为新的独立加分项。

**状态诊断证据**：确认的 36 个有效点里，邻居投影方差与其位置迹除以 3 的最大差仅 2.78×10⁻¹⁷ m²；本机投影方差与其位置迹除以 3 则可相差 3.03 m²。因而前者在此场景只是迹的冗余编码，后者确实表达方向性。两位参考 AoI 差始终为零。增加方向编码未在独立确认形成稳定的邻居排序规律。

最小代理各种子排序准确率为 2026101321：0.625，2026101322：0.2，2026101323：0.3333，2026101324：不可得；仅一个种子满足准确率大于 0.5 且 Spearman 为正。未达到原 0.65/0.20/3-of-4 门槛。

## 6. 奖励有效性与反事实范围

offline `current_SSE_gain − 0.01×cost`、`four_state_SSE_gain − 0.01×cost` 只作真实收益评价标签。它们不是执行期奖励，也没有进入 Actor 或规则。每个假想邻居分支记一次成本，即使门控拒绝；none 为零。不能将未执行的假想分支成本当作实际网络流量。

采用决策前合法动作集合修正离线最优上界，避免把不合法邻居的收益当成可选机会。三个确认种子的 36 个有效点：原评分相对合法四状态净收益最优标签的平均 regret 为 0.1357 m²，最小代理为 0.6328 m²；两者均非因果整段策略损失。即时真实净标签与短期真实净标签的离线最优动作一致率为 100%，其收益差 Spearman 近 1。**这种真值标签之间的一致性不能证明存在可部署的奖励或状态预测器。** 两个邻居请求成本相同，减去同一成本也不会改善其相互排序。

当前+三次未来状态的反事实固定 Random 轨迹、实际量程、消息/缓存及本地传感器包；不包含新消息队列或导航反馈。真实闭环则使用各策略自身的请求、原生队列和导航反馈。六个条件式检查点收益与整条 Random-versus-None 平均 SSE 收益的确认描述相关为 Pearson 0.9913、Spearman 0.9429，但仅六个几何块、三个独立种子，且反馈/历史不同；不得据此推出预测未来累计定位收益或因果分解。

真实收益差还包含未观测的实际估计误差方向以及随机创新。单次真值最优邻居不同，不等于这些差异都可由决策前状态预测。下一步应先检验执行信息条件下的**期望净收益**，区分不可约随机差异与可预测信号；不能直接把离线 oracle 当作奖励训练。
