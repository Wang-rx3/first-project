# 6 讨论与局限性

## 6.1 数据集策略的合理性

本课题使用纯 Python 环境生成统一数据，定位、测距图、通信质量和 MAPPO 联合优化共享同一坐标、时间、动作和场景状态。该策略避免外部数据字段不一致和不可控许可证问题，但必须通过敏感性分析、重复随机种子和清晰的仿真假设说明结论边界。

## 6.2 当前局限

- 当前环境采用有界三维运动学模型，不能替代完整六自由度气动动力学；
- 通信丢包、时延和 AoI 是统计模型输出，需要通过参数扫描和重复种子检查稳健性；
- 纯 Python 仿真真值用于环境转移和离线评价，不代表真实飞行测量；
- 结论的外部有效性需要在后续 PX4/Gazebo 或真实飞行接口实验中单独验证。

## 6.3 后续工作

在纯 Python 模型稳定后，使用 PX4 + Gazebo 进行飞控接口和半实物迁移验证；该阶段是工程迁移，不改变当前“实验数据全部由 Python 生成”的论文主数据路线。
