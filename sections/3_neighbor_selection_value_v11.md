## Greedy设计及输入边界

十字段全部为执行期可获得信息：自身和收到的邻居**三维位置块**协方差迹、估计距离、两个估计方向的共同夹角、本地incoming-link RSSI、当前时刻减send_time的packet age。邻居均值/P仅来自已经到达的消息，不能从参考机私有EKF或真值读取。last_propagated_time表示状态传播时间，不代表原信息新鲜度。

Greedy额外使用完整本机15维P、三维估计方向及已收到缓存历史，所以不能说它只用了十标量。全15维迹含混合状态单位，仅作数值监视；定位信息项只用3D位置块迹。

唯一固定评分（字段名避免符号表冲突）：

```text
score = (information_fraction + geometry + reliability - communication_cost) / 4
information_fraction = 当前原CI克隆的位置迹下降 / 当前位置迹
geometry = 估计单位方向上的本机位置协方差投影 / 位置迹
reliability = 0.75 / (0.75 + 收到的邻居位置迹)
communication_cost = (RSSI弱度 + packet_age / TTL) / 2
```

0.75来自原GNSS三维测量方差3×0.5²；RSSI按原阈值−100dBm至发射功率上界10dBm固定归一化。各分量按预定界处理，不拟合尺度或调权。none分数0，只有正的最佳合法候选才请求；平分用独立索引流，不按标签偏置。缺失/旧包/过期/RSSI无效等评分null、有原因；真实门控和预算不降低。

信息项只在克隆上使用当前估计的零创新预测、原LOS方差0.08²和原CI核，复用51点缓存CI及20点相对CI，不用v9旧线性信用作为Greedy评分。没有未来测距、下一步传感器或真值输入。**克隆后的协方差降低仍是代理，不是真实误差改善保证。**

在线行动在当前已可得观测上锁定；随后原生预算、运动、本地更新、消息到达、CI融合和导航反馈。反事实快照只在post-local/pre-coop复制给离线分析，时间比行动晚0.2秒，不能用于当前选择。

## 已确认的问题及尚待验证因素

1. **固定评分把信息潜力/可靠性当成正收益加分。** 确认Greedy的232个窗口中194个两源都预测原CI不更新，却仍全部请求。几何和可靠性项产生正分，无法与none=0形成合理“无有效信息→不花成本”的权衡。它是本轮固定启发式的效用设计限制，不是在线CI接口故障；本轮未据此改权重、门限、奖励或请求规则。
2. **十标量存在方向信息缺失。** 纯代数反例：同一位置协方差diag[9,1,2]、两邻居等距离/等协方差/等RSSI/AoI且夹角90°，交换它们的x/y方向后十标量完全相同，两个方向项从0.75/0.0833反转。反例无新物理步或滤波更新。它证明十标量不能唯一描述方向不确定度，不证明补齐方向即可学会真实收益；本轮扩展Greedy已用完整P和方向，仍未通过。
3. **可解释差异大小与可排序最佳源不同。** 确认48点，共享夹角与真实差幅度Spearman约0.579；其对两个候选是共同量，不能直接判哪个优。来源迹/距离/RSSI/AoI差与真实有符号差相关弱或种子/几何依赖；原CI预测信息差相关约−0.013，完整score差相关−0.066。限制到22个可区分点score Spearman仍只有0.051。窗口相关不当作独立样本的显著性结果。
4. **隐藏均值误差、未来测量噪声、时序和未知相关性仍可能影响真实效用。** 评分在行动时，实际融合晚0.2秒；这并非接口错位，但当前瞬时零创新代理未预测实际local-update后的条件状态。它们各自贡献尚未分离，不强行归因，也不修改原滤波器。

旧线性代理在Random开发/确认分别222/232、218/232窗口满足差>1e−6，均超过原30标准；该门槛没有降低。它不能替代真实价值/排序检验。原CSV列`old_linear_credit_gap_over_1e6`名字省略负号，实际源代码比较始终为`>1e-6`；上述数值按该实际阈值解释，不是1e6。

**判据补审计**：冻结gate分别数了两项改善种子，不能在一般情况下替代“同一种子两项同时改善”。新增只读`neighbor_selection_joint_audit_v11.py`按原协议重算联合计数，确认每几何均1/4，不通过；原冻结源码、报告与数据保留，阈值和当前有条件结论未变化。另一个纯测试证明“两项各3/4，但交集2/4”不能通过。没有事后选候选、改验收或重新仿真。
