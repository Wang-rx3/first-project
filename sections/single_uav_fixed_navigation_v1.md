# 单UAV固定基础导航与本地EKF验证 v1

日期：2026-10-11。仅第一阶段单UAV执行层验证；不训练PPO、BC/DAgger或MAPPO，不运行多UAV性能实验，不提交或推送。所有新配置、场景、逐步日志和图分别进入`data/`、`logs/`、`plots/`下的独立`single_uav_fixed_navigation_v1_seed2026_20261011/`目录。历史控制器、环境、学习核心及结果保持SHA保护。

## 实现与冻结合同

复用`src/experiments/baseline.py`独立固定基线的local estimate/goal动作契约，以及现有MotionConfig、clip_vector_norm、LocalEKF、MultiUAVJointEnv和strict停车适配器。新增独立纯控制模块，不启用旧goal-recovery或其他学习动作辅助。

固定的位置增益0.6每秒、速度反馈增益1.6每秒、巡航速度上限2.5 m/s。先由参考点与本机EKF估计位置的误差生成有限速度目标，再由目标速度与本机估计速度的误差生成加速度，乘原0.2 s周期转换为世界坐标速度增量。近目标未饱和区域等价于PD反馈，无积分项。输出逐轴限制为0.6/sqrt(3) m/s、总范数≤0.6 m/s，继续通过原动作执行与基础安全投影。

原名义速度上限12 m/s、加速度3 m/s²、边界、legacy基础安全距离2 m、120步/24 s和五类辅助关闭设置不变。成功使用真实距离≤1 m、真实速度≤0.5 m/s、连续5个决策步、无碰撞；实体任务另用原physical pass和2.5 m严格clearance合同。controller只接收本机原始EKF position/velocity及静态mission reference；不接收env、truth、reward或邻机真值。真值只作控制之外的评估日志。

基础环境reset由初始真状态建立LocalEKF，这一有利初始化保持原合同并明确披露。四个估计偏置挑战只改变初始belief：位置偏置范数0.4 m、速度偏置范数0.2 m/s，实际植物不改；必须重新构建graph并刷新观测。它们不是完全未知初态/长期传感器故障验证。

## 登记的阶段与停止条件

增益、完整场景清单及门槛均在首次环境推进前锁定，开发集和独立评估集不重用。禁止读取验证结果调参或失败重跑挑选结果。

1. 六个开发场景覆盖三轴正负方向、8/12 m、静止/朝向/背离/切向初速。6/6严格停车、合法动作、无碰撞/接触/安全或边界投影，才进入评估。
2. 36个无障碍评估：32个常规场景（三轴正负＋八个3D对角方向、4/12/20/30 m、四种初速regime），加4个独立geometry的belief偏置挑战。总成功36/36、每regime≥95%按整回合取整、偏置4/4，无碰撞/接触/边界/安全修正，动作及实际加速度合规。静止场景要求从0主动加速并在保持前命令负纵向增量、实际减速；27个移动场景中至少14个场景要求保持前至少一次上述制动证据。
3. 四个水平面matched场景用静止、朝向1.5、背离1、切向1 m/s分别比较零增量coast与固定控制。固定4/4成功、coast0/4，防止把低速自然滑行当成反馈控制。
4. 只有上述门槛通过后才运行4个简单静态盒障碍场景，两套90°旋转独立几何各左右绕行。盒尺寸3×3×8 m，位于24 m航程的12 m处；已知地图mission参考点分别在下游7/17 m、侧向±5.5 m，然后最终目标。中间参考仅按EKF距离≤0.8 m切换，环境final goal不改。要求4/4实体pass＋严格停车、无碰撞/接触/边界，实际最小clearance≥2.5 m。安全修正单独报告，不能称其为自主避障。能力仅限已知静态地图上的预定义waypoint路线。

每个episode最多120步，无成功后继续执行、无补满步数、无训练。研究环境步硬上限6480：开发720＋无障碍4320＋paired960＋障碍480；工程测试环境步另计，优先纯函数测试0步。

开发场景固定顺序为：+X/8 m/静止、−X/12 m/朝向1.5 m/s、+Y/8 m/背离1 m/s、−Y/12 m/切向1 m/s、+Z/8 m/静止、−Z/12 m/朝向1.5 m/s；ID为`fixednav_dev00..05`，噪声seed为2026114100..4105，初始化位置/目标由固定中点及半程位移生成。所有阶段显式safety2_enabled=true、assist_mask="00000"，即基础安全投影开启、五辅助关闭；安全模式及五辅助开关相同，每行CSV记录该模式；paired不改变传感器或执行模式。

制动证据冻结为：保持前已出现朝向当前参考的实际速度>0.05 m/s（静止场景曾加速到>0.5）；请求增量在同一动作前EKF参考方向上的投影<−0.0001 m/s，同时实际速度在该固定方向上的投影减少>0.001 m/s，并另记实际速率减少。36场景每regime9例，95%按整回合向上取整需9/9，因此综合门槛实际要求36/36。

障碍实例初始化静止、belief偏置零，噪声seed2026114400..4403；第一套起点[55,110,22]、第二套[110,70,28]，按上述方向构造静态盒与参考点。当前运动模型把UAV视为点，clearance是该点/步内运动线段到盒表面的距离，没有额外机体半径。复用33采样点的segment clearance及精确线段相交判断，另按采样间隔给出距离下界，避免将采样最小值当成精确连续最小值。保守下界也要求≥2.5 m。
